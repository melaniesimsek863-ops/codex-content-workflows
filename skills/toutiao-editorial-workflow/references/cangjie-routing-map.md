# Cangjie Routing Map

Use `cangjie-book-skills` as a method library. Load only the selected module.

| Need | Preferred module | Boundary |
|---|---|---|
| Market and audience research | `research-four-steps` | Does not replace current source verification |
| Translate features to reader benefit | `feature-to-benefit` | Best for practical or commercial content |
| Design or evaluate titles | `headline-four-functions`, `headline-eight-types`, `headline-four-formulas` | Platform title rules override formulas |
| Support trust with evidence | `factual-evidence` | Precision must come from real sources |
| Diagnose shareability | `stepps-diagnostic` | Not a writing or fact-quality method |
| Commercial conversion | `copywriting-four-step-system` and selected viral-copywriting modules | Do not use as the default editorial skeleton |
| Humanize prose | `human-voice-pass` | Does not verify facts, rights, or originality |
| Story or drama content | `ai-comic-drama-writer` | Use only when the actual format is narrative drama |

Treat `news-editorial-title` cautiously. Its legacy use of famous names, urgency, and news language can conflict with current Toutiao title rules unless the facts and context fully support the wording.
