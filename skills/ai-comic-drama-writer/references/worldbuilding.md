# Worldbuilding

Worldbuilding must generate plot pressure. A setting is useful only if it changes what characters can do.

## World Rules

For speculative, suspense, fantasy, sci-fi, or rule-based stories, define:

1. visible rule
2. hidden rule
3. cost of violation
4. loophole
5. who knows the rule
6. who benefits from the rule
7. how the rule escalates

## Setting Function

Every key location should serve one function:

- safety that becomes unsafe
- public place hiding private truth
- maze that controls movement
- status symbol
- memory trigger
- surveillance zone
- forbidden resource
- emotional anchor

## AI Comic Continuity

Record stable visual anchors:

- recurring locations
- lighting palette
- character outfits
- props
- symbols
- room layout
- weather/time cues

Do not change character hair, clothing logic, or spatial layout accidentally between episodes unless story requires it.
