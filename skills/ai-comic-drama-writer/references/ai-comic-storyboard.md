# AI Comic Storyboard

AI comic scripts must be drawable. Avoid vague literary description when a shot needs visual generation.

## Shot Fields

Use these columns by default:

| shot | panel | camera | visual | character action | dialogue | narration | emotion | image prompt | continuity |

## Visual Prompt Ingredients

For each important image prompt include:

- character identity and stable descriptors
- clothing and key prop
- location
- camera distance and angle
- action
- facial expression
- lighting
- mood
- style direction if requested
- continuity note

## Camera Vocabulary

- close-up: emotion, clue, threat
- medium shot: dialogue and relationship
- wide shot: setting and isolation
- over-the-shoulder: confrontation
- low angle: power
- high angle: vulnerability
- insert shot: clue or object
- silhouette: mystery or concealment

## Panel Rhythm

For vertical AI comic drama:

1. first panel must carry a visual hook
2. every 3-5 panels should change emotional pressure
3. dialogue panels need visual action, not talking heads only
4. end on a panel that creates a question or shock

## Production Notes

When asked for AI generation prompts, keep character descriptors consistent across shots. If the user has a model or style requirement, put it in a separate `style anchor` field rather than rewriting every panel loosely.
