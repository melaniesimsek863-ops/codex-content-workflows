# Scene And Dialogue

## Scene Test

A scene must change at least one thing:

- information
- relationship
- power
- danger
- emotion
- plan
- self-understanding

If nothing changes, cut or merge it.

## Scene Beat Pattern

1. visual entry
2. immediate tension
3. character objective
4. resistance
5. tactic shift
6. reveal or reversal
7. exit image or line

## Dialogue Rules

- Make dialogue do more than explain. It should reveal desire, hide truth, attack, defend, seduce, test, or delay.
- Put exposition into conflict. If a fact matters, make someone need it, hide it, distort it, or pay for it.
- Let characters misunderstand for character-specific reasons, not because the plot needs delay.
- Use subtext: the spoken line and real intention should often differ.

## Dialogue Polish Pass

Check each line:

1. Can it be shorter?
2. Could another character say the same line? If yes, add voice.
3. Does it reveal action or emotion? If no, cut.
4. Is it explaining what the image already shows? If yes, remove.
5. Does it create a turn? If no, weaken or cut.

## Voice Tags

Use stable voice tags for major characters:

- controlled and cold
- warm but evasive
- childish directness
- educated cruelty
- comic literalism
- poetic grief
- streetwise speed
- official bureaucratic tone
