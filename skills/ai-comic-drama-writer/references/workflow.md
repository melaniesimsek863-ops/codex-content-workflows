# Workflow

## Intake Defaults

If the user does not specify details, assume:

- language: Chinese
- platform: Douyin/Kuaishou/Bilibili-style vertical video unless stated otherwise
- format: AI comic drama with visual storyboard
- target: strong opening, high retention, clear emotional payoff
- originality: structural inspiration allowed, plot imitation forbidden

Ask at most one clarifying question when the missing answer changes the whole project. Otherwise proceed with assumptions.

## Project Modes

### Seed Mode

Use when the user gives only an idea, image, title, trope, emotion, or reference. Produce:

1. core premise
2. audience promise
3. protagonist and opponent
4. conflict engine
5. 3 alternate directions
6. recommended direction

### Short Mode

Use for 15s, 30s, 60s, 3min, single-episode, or 3-10 episode scripts. Prioritize hook density, fast conflict, visual clarity, and one strong reversal.

### Series Mode

Use for 10+ episodes. Create a bible before writing full scripts. Track arcs, secrets, reveals, reversals, episode hooks, and payoff obligations.

### Rewrite Mode

Use when the user provides draft text. Diagnose first, then rewrite. Never rewrite blindly. Identify the weakest layer: premise, character, conflict, scene, dialogue, visuality, continuity, or market hook.

### Production Mode

Use when the user wants storyboard, prompts, shot list, voiceover, subtitles, title, or release package. Convert the story into production fields without changing core story unless necessary.

## Deliverable Ladder

Work from abstract to concrete:

1. logline
2. story engine
3. character bible
4. outline
5. episode beats
6. scene script
7. storyboard
8. visual prompts
9. title and posting copy
10. quality report
